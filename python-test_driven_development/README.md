# Python - Test-driven development

## Task 0. Integers addition

Write a function that adds 2 integers: def add_integer(a, b=98). Floats are cast to integers, and a TypeError is raised if a or b is not an integer or a float.

- File: `0-add_integer.py`
- Tests: `tests/0-add_integer.txt`

## Task 2. Matrix division

Write a function that divides all elements of a matrix: def matrix_divided(matrix, div). Elements are divided by div, rounded to 2 decimal places, and a new matrix is returned.

- File: `2-matrix_divided.py`
- Tests: `tests/2-matrix_divided.txt`

## Task 3. Say my name

Write a function that prints My name is <first name> <last name>: def say_my_name(first_name, last_name=""). A TypeError is raised if first_name or last_name is not a string.

- File: `3-say_my_name.py`
- Tests: `tests/3-say_my_name.txt`

## Task 4. Print square

Write a function that prints a square with the character #: def print_square(size). A TypeError is raised if size is not an integer (including negative floats), and a ValueError if size is less than 0.

- File: `4-print_square.py`
- Tests: `tests/4-print_square.txt`
