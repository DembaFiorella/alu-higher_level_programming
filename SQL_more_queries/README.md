# SQL more queries
MySQL scripts for managing users, privileges, and databases.

## Task 11. All shows

Write a script that lists all shows contained in the database hbtn_0d_tvshows, with genre_id or NULL if the show has no genre.

- File: `11-genre_id_all_shows.sql`

## Task 12. No genre

Write a script that lists all shows contained in hbtn_0d_tvshows without a genre linked.

- File: `12-no_genre.sql`

## Task 13. Number of shows by genre

Write a script that lists all genres from hbtn_0d_tvshows and displays the number of shows linked to each.

- File: `13-count_shows_by_genre.sql`

## Task 14. My genres

Write a script that uses the hbtn_0d_tvshows database to list all genres of the show Dexter.

- File: `14-my_genres.sql`

## Task 15. Only Comedy

Write a script that lists all Comedy shows in the database hbtn_0d_tvshows.

- File: `15-comedy_only.sql`
